## Часть 2 — Исправленные версии

### Изменения в `src/lib.rs`

**`leak_buffer`** — убраны raw-указатели, утечка устранена:
```rust
// было: Box::into_raw без Box::from_raw
// стало:
pub fn leak_buffer(input: &[u8]) -> usize {
    input.iter().filter(|&&b| b != 0).count()
}
```

**`use_after_free`** — убран dangling-доступ, `unsafe fn` → `fn`:
```rust
// было: val + *raw  (raw уже freed)
// стало:
pub fn use_after_free() -> i32 {
    let val = *Box::new(42_i32);
    val + val
}
```
